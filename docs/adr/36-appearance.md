# ターミナルの配色とフォントの大きさは参加者ごとにし、ブラウザに保存する

- 日付: 2026-10-16
- ストーリー: #36

## 背景

ターミナルの配色（テーマ）とフォントの大きさを、ブラウザの画面から変えられるようにする。これまで Accompany は「参加者全員で同じ画面を共有する」方針で、タブ・分割の配置・端末の大きさは全員で共有している。見え方の設定をどこまで共有するか、どこに保存するか、フォントの大きさと端末の大きさ（参加者のうち一番小さい表示領域に合わせる。#5）をどう整合させるか、キーボードショートカットを入れるかを決める必要があった。

## 検討した選択肢

### 設定の持ち方

1. 参加者全員で共有する（サーバーが持ち、`/ws/workspace` で配る）
2. 参加者ごとにし、ブラウザ（localStorage）に保存する
3. 参加者ごとにし、保存しない

### 配色の選び方

1. 組み込みのテーマから選ぶ（暗い / 明るい / 見やすさ重視）
2. 色を 1 つずつ編集できるようにする

### フォントの大きさのキーボードショートカット

1. ⌘= / ⌘- （Ctrl+= / Ctrl+-）を横取りする
2. ⌘⇧ / Ctrl+Shift の組み合わせで別のキーを割り当てる
3. 入れず、設定の画面だけにする

## 決定

- 設定の持ち方: 選択肢 2。参加者ごとにし、localStorage の `accompany.appearance` に `{ theme, fontSize }` を JSON で保存する。読めない・壊れている・範囲外の値は既定値（暗い、15px）にする。保存できないときも、開いている間は使う
- 配色の選び方: 選択肢 1。暗い（既定）・明るい・見やすさ重視（黒地に白、WCAG AAA を満たす）の 3 つ。配色を変えるのはターミナルの部分だけで、タブバーやペインのバーは暗いままにする
- フォントの大きさ: 8〜32px の整数。タブバーの「表示の設定」（⚙）から変える。変えたら、表示中の全ターミナルで xterm の `fontSize` を変え、自分の表示領域に収まる列数・行数をサーバーに伝え直す（`Pane.setAppearance` → `sendSize`）。端末の大きさは、これまでどおりサーバーが参加者のうち一番小さいものに決めて全員に配る
- キーボードショートカット: 選択肢 3。入れない

## 理由

- 設定の持ち方: 配色やフォントの大きさは、見る人の目・画面・好み（明るい部屋かどうかなど）による。共有すると、ある人が見やすくした変更がほかの人には見にくくなる。全員で共有しているのは「何が表示されているか」（端末の中身・配置・大きさ）で、「どう見えるか」は人ごとに変えても画面の共有を妨げない。保存先は、認証（#7）がまだなく参加者を次回も同じ人と識別できないので、サーバーではなくブラウザにする。外部への依存も増えない
- 配色の選び方: 色の編集画面は大きく、ストーリーの完了条件には不要。組み込みのテーマで、暗い・明るい・見やすさの 3 つの需要を満たせる。暗いテーマは、xterm.js 6 の既定（黒地に白 `#fff` の文字）から文字色だけページの文字色（`#ccc`）にそろえ、見やすさ重視と区別できるようにした
- フォントの大きさと端末の大きさ: フォントを大きくすると 1 文字の幅・高さが増え、同じ表示領域に収まる列数・行数が減る。表示領域の大きさ（`ResizeObserver`）は変わらないので、フォントを変えたときに明示的に伝え直す必要がある。伝え直せば、ほかの参加者の端末も小さくなる（大きいフォントの人の画面からはみ出さないため）。これはウィンドウを小さくしたときと同じ扱いで、#5 の仕組みに沿う
- キーボードショートカット: ⌘= / ⌘- と Ctrl+= / Ctrl+- はブラウザのズームで、ページで横取りするとブラウザのズームが使えなくなる（ズームでも同じく列数・行数が変わるので、代わりとして使える）。⌘⇧= などはキー配列によって `=` と `+` の扱いが違い、Chrome が予約しているかどうかも配列ごとに確かめる必要がある。迷ったので入れず、設定の画面だけにした

## 影響・今後の課題

- フォントを大きくした参加者がいると、ほかの参加者の端末も小さくなる。気になる場合は、大きくした人が別のタブ・分割を使うなどで対処する。必要になれば、端末の大きさの決め方（#5）を見直す
- 配色の共有（例: 発表者の配色に全員を合わせる）、色の編集、フォントの種類の変更、フォントの大きさのショートカットは扱わない
- タブバーやペインのバー、検索バーなどの配色は変えない。明るいテーマでは、ターミナルの部分だけが明るくなる
